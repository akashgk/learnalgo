# Word Ladder

**Difficulty:** Hard | **Category:** Graphs | **Pattern:** BFS on an implicit graph | **Source:** LeetCode 127; Striver A2Z, NeetCode 150

## The problem

Transform `beginWord` into `endWord` by changing **one letter at a time**, where every intermediate word (and `endWord`) must be in `wordList`. Return the number of words in the shortest such sequence, including both ends, or 0 if impossible.

```
beginWord = "hit", endWord = "cog"
wordList = [hot, dot, dog, lot, log, cog]
hit -> hot -> dot -> dog -> cog      ->  5
```

## Step 1: See the graph

Words are **nodes**. Two words are connected by an **edge** if they differ in exactly one position. The question "fewest transformations" is **shortest path in an unweighted graph**, and that is **BFS**.

DFS would find *a* path, not the shortest one, unless it explored everything.

## Step 2: How to find neighbors

**Option A:** compare the current word with every word in the list: O(N * L) per word, O(N^2 * L) total. Fine for small lists, slow for N = 5000.

**Option B:** generate candidates. For each position, try all 26 letters and check whether the result is in a hash set of dictionary words. That is `26 * L` candidates per word, each costing O(L) to build and hash: O(26 * L^2) per word, O(N * 26 * L^2) total. With short words and long lists, this is much faster.

**Option C (mention it):** precompute "generic patterns" like `h*t`, mapping each pattern to the words that match it. Neighbors of a word are the words sharing any of its L patterns.

## Step 3: BFS details

- The queue holds `(word, stepsSoFar)`, starting with `(beginWord, 1)`.
- Use the dictionary set itself as the "unvisited" set: **remove a word when it is enqueued.** Then no word is enqueued twice, and no separate visited set is needed.
- The first time `endWord` is dequeued, its step count is the answer (BFS dequeues nodes in order of distance).

**Why remove on enqueue and not on dequeue?** If you mark on dequeue, the same word can be enqueued many times by different neighbors at the same level before it is ever dequeued, blowing up the queue.

## Step 4: The code

Full source: [`word_ladder.dart`](word_ladder.dart) (run it with `dart run`).

```dart
// Word Ladder: length of the shortest transformation sequence from beginWord to endWord,
// changing one letter at a time, every intermediate word in wordList. 0 if impossible.
// BFS over words; neighbors generated by trying all 26 letters at each position.
// O(N * L * 26) time (N words of length L, string building adds another factor L), O(N * L) space.

import 'dart:collection';

int ladderLength(String beginWord, String endWord, List<String> wordList) {
  final unvisited = wordList.toSet();
  if (!unvisited.contains(endWord)) return 0;
  final queue = Queue<(String, int)>()..add((beginWord, 1)); // (word, words in the sequence so far)
  unvisited.remove(beginWord);
  while (queue.isNotEmpty) {
    final (word, steps) = queue.removeFirst();
    if (word == endWord) return steps;
    final chars = word.codeUnits.toList();
    for (var i = 0; i < chars.length; i++) {
      final original = chars[i];
      for (var c = 97; c <= 122; c++) {
        if (c == original) continue;
        chars[i] = c;
        final next = String.fromCharCodes(chars);
        // Removing on enqueue (not on dequeue) keeps every word in the queue at most once.
        if (unvisited.remove(next)) queue.add((next, steps + 1));
      }
      chars[i] = original;
    }
  }
  return 0;
}
```

### Walkthrough

- `if (!unvisited.contains(endWord)) return 0;` is a quick exit: the target must be in the list.
- `unvisited.remove(next)` returns true only if `next` was an unvisited dictionary word, so it doubles as the membership test and the visited marking.
- `chars[i] = original` restores the position before moving to the next one.

## Step 5: Dry run

| dequeued (steps) | new words enqueued (steps) |
|---|---|
| hit (1) | hot (2) |
| hot (2) | dot (3), lot (3) |
| dot (3) | dog (4) |
| lot (3) | log (4) |
| dog (4) | cog (5) |
| log (4) | none (cog already enqueued) |
| cog (5) | return **5** |

## Complexity

- Time: **O(N * 26 * L^2)** with candidate generation (N words, length L).
- Space: **O(N * L)** for the set and queue.

## Edge cases

- `endWord` not in the list: 0.
- `beginWord` in the list: it is removed at the start so it is not revisited.
- No path: the queue empties, return 0.

## Common mistakes

- DFS instead of BFS.
- Marking visited on dequeue (queue explosion).
- Counting transformations instead of words (off by one: the answer counts `beginWord` too).

## Follow-ups you should be ready for

1. **Bidirectional BFS.** Search from both ends, always expanding the smaller frontier; stop when they meet. Cuts the explored area dramatically for large dictionaries.
2. **Word Ladder II (LeetCode 126): return all shortest sequences.** BFS level by level while recording parents (all of them), then DFS/backtrack from `endWord` over the parent graph. Remove words from the set per **level**, not per word, so multiple parents at the same level are kept.
3. **Minimum Genetic Mutation (LeetCode 433).** Same problem with a 4-letter alphabet.

## What to remember

"Minimum number of single steps" means BFS. When the graph is not given, generate neighbors on the fly and mark nodes visited when they are enqueued.
