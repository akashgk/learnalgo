# Smallest Substring Containing

**Difficulty:** Very Hard | **Category:** Strings | **Pattern:** Variable-size sliding window with counts

## The problem

Given a big string and a small string, return the **smallest substring** of the big string that contains **every character** of the small string, **including duplicates** (if the small string has two `$`, the substring needs at least two `$`). Return `""` if impossible. Assume a unique answer.

```
big = "abcd$ef$axb$c$", small = "$$abf"  ->  "f$axb$"
```

## Step 1: Brute force

Check every substring (O(b^2)) for containment (O(b) with counts): **O(b^3)**.

## Step 2: Sliding window

Maintain a window `[left, right]`:

1. **Expand** `right` until the window contains everything required.
2. Then **shrink** from `left` as far as possible while it still contains everything, recording the smallest valid window.
3. When shrinking breaks validity, go back to expanding.

Each index enters the window once and leaves once: O(b).

## Step 3: Checking validity in O(1): the "missing" counter

Comparing count maps on every step would cost O(alphabet). Instead:

- `need[c]` = how many more copies of `c` the window still needs (it can go **negative**, meaning surplus copies);
- `missing` = the total number of required characters (with multiplicity) not yet covered.

Rules:

- **Adding** character c: if `need[c] > 0`, it covers something, so `missing--`. Then `need[c]--`.
- **Removing** character c: `need[c]++`. If `need[c] > 0` afterwards, a required copy was lost, so `missing++`.

The window is valid exactly when `missing == 0`. Surplus copies (negative `need`) can be removed without breaking validity, which is what lets the window shrink past them.

## Step 4: The code

Full source: [`smallest_substring_containing.dart`](smallest_substring_containing.dart) (run it with `dart run`).

```dart
// Smallest Substring Containing: shortest substring of bigString containing every character of
// smallString (with multiplicity). Sliding window with a "missing" counter.
// O(b + s) time, O(alphabet) space.

String smallestSubstringContaining(String bigString, String smallString) {
  final need = <int, int>{};
  for (final c in smallString.codeUnits) {
    need.update(c, (v) => v + 1, ifAbsent: () => 1);
  }
  var missing = smallString.length; // characters still required, counting multiplicity
  var bestStart = 0, bestLen = -1;
  var left = 0;
  for (var right = 0; right < bigString.length; right++) {
    final c = bigString.codeUnitAt(right);
    if (need.containsKey(c)) {
      if (need[c]! > 0) missing--;
      need[c] = need[c]! - 1; // may go negative: surplus copies inside the window
    }
    while (missing == 0) {
      if (bestLen == -1 || right - left + 1 < bestLen) {
        bestStart = left;
        bestLen = right - left + 1;
      }
      final lc = bigString.codeUnitAt(left++);
      if (need.containsKey(lc)) {
        need[lc] = need[lc]! + 1;
        if (need[lc]! > 0) missing++; // removed a required copy
      }
    }
  }
  return bestLen == -1 ? '' : bigString.substring(bestStart, bestStart + bestLen);
}
```

### Walkthrough

- `need` is built from the small string; `missing` starts at its length.
- For each `right`: update `need` / `missing` for the added character.
- While valid: record the window if it is the smallest so far, then remove `bigString[left]` and advance `left`, updating `need` / `missing`.
- Return the best window (or `""`).

## Complexity

- **Time: O(b + s)**: each index enters and leaves the window at most once.
- **Space: O(alphabet)** for the counts.

## Common mistakes

- Ignoring duplicates in the small string.
- Checking validity by comparing whole maps (correct but slow).
- Recording the window after shrinking instead of before.

## Follow-ups

1. **Minimum Window Substring (LeetCode #76):** identical; one of the most frequently asked hard string problems at Meta, Google, and Amazon.

## What to remember

Expand until valid, shrink while valid. A single `missing` counter plus per-character needs (allowed to go negative) makes the validity check O(1).
