# Longest Balanced Substring

**Difficulty:** Very Hard | **Category:** Strings | **Pattern:** Two counter scans (or a stack of indices)

## The problem

Given a string of `(` and `)`, return the length of the **longest substring** that is balanced (every opener has a matching closer after it, properly nested).

```
"(()))("    ->  4     "(())"
"(()"       ->  2     "()"
"()(()())"  ->  8     the whole string
```

## Step 1: Brute force

Check every substring with a counter: O(n^2) substrings, O(n) each: O(n^3). (With a counter extended per start index: O(n^2).)

## Step 2: Stack of indices (O(n) time, O(n) space)

Keep a stack of indices, starting with `-1` as a "base" (the position before the current valid run).

- `(`: push its index.
- `)`: pop. If the stack is now empty, this `)` is unmatched: push its index as the new base. Otherwise, the current valid run is `i - stack.top` long.

This is a solid answer. Can we avoid the stack?

## Step 3: Two counter scans (O(1) space)

Scan **left to right** counting opens and closes:

- when `opens == closes`, the stretch since the last reset is balanced: record `2 * closes`;
- when `closes > opens`, the stretch can never become balanced: reset both counters.

This misses runs where openers are always in the lead and never catch up, like `"(()"`: at the end, opens = 2, closes = 1, never equal. So scan again **right to left** with the roles swapped (reset when `opens > closes`). A balanced run that the left scan misses because of extra `(` before it is found by the right scan, and vice versa.

## Step 4: The code

Full source: [`longest_balanced_substring.dart`](longest_balanced_substring.dart) (run it with `dart run`).

```dart
// Longest Balanced Substring of '(' and ')'. Two scans with counters (left-to-right and
// right-to-left) catch every balanced run. O(n) time, O(1) space.

int longestBalancedSubstring(String string) {
  int scan(bool leftToRight) {
    var open = 0, close = 0, best = 0;
    final n = string.length;
    for (var k = 0; k < n; k++) {
      final ch = string[leftToRight ? k : n - 1 - k];
      if (ch == '(') {
        open++;
      } else {
        close++;
      }
      if (open == close) {
        if (2 * close > best) best = 2 * close;
      } else if (leftToRight ? close > open : open > close) {
        open = close = 0; // prefix can no longer be balanced: restart
      }
    }
    return best;
  }

  final a = scan(true), b = scan(false);
  return a > b ? a : b;
}
```

### Walkthrough

- `scan(leftToRight)` implements one direction; the reset condition flips with the direction.
- The answer is the maximum of both scans.

## Step 5: Dry runs (generated by running the algorithm)

`"(()"`, left to right:

| char | opens | closes | best |
|---|---|---|---|
| ( | 1 | 0 | 0 |
| ( | 2 | 0 | 0 |
| ) | 2 | 1 | 0 |

Never equal: the left scan finds 0. Right to left:

| char (from the end) | opens | closes | best |
|---|---|---|---|
| ) | 0 | 1 | 0 |
| ( | 1 | 1 | **2** |
| ( | 2 > 1: reset | | 2 |

Answer: 2. This is why both scans are needed.

`"(()))("`, left to right: the counters become equal after `"(())"` (best 4), then the third `)` makes closes > opens (reset), and the final `(` never closes. Answer: 4.

## Complexity

| Approach | Time | Space |
|---|---|---|
| Brute force | O(n^2) to O(n^3) | O(1) |
| Stack of indices | O(n) | O(n) |
| Two counter scans | O(n) | O(1) |
| DP (`dp[i]` = length of the valid run ending at i) | O(n) | O(n) |

## Common mistakes

- A single scan (fails on `"(()"` or on `"())"` depending on the direction).
- Forgetting to reset the counters.

## What to remember

Counter scans find balanced runs, but each direction is blind to a surplus on one side. Scan both ways and take the maximum.
