# Blind 75 and Grind 75 in this repo

Every problem on both lists is solved somewhere in this repository. Almost all of them were already covered by the earlier sets; the 13 folders here are the ones that were missing:

- **12 from Grind 75:** Flood Fill, Implement Queue using Stacks, First Bad Version, Longest Palindrome, Add Binary, 01 Matrix, Lowest Common Ancestor of a Binary Tree, String to Integer (atoi), Find All Anagrams in a String, Minimum Height Trees, Basic Calculator, Maximum Profit in Job Scheduling.
- **1 from Blind 75:** Combination Sum IV (the original Blind 75 post links LeetCode 377 under "Combination Sum").

The tables below map all 75 problems of each list to the folder that solves them.

| List | Where the 75 live |
|---|---|
| Blind 75 | neetcode/ 27, medium/ 18, more_problems/ 13, hard/ 12, very_hard/ 3, easy/ 1, this folder 1 |
| Grind 75 | medium/ 24, neetcode/ 14, this folder 12, more_problems/ 10, hard/ 9, easy/ 4, very_hard/ 2 |

**Which list should you use?**

- **Blind 75** is the classic minimum set: every core pattern once. It is a subset of NeetCode 150 except for Combination Sum IV.
- **Grind 75** (by the author of Blind 75) is ordered as an 8-week schedule that starts easy and ramps up, and adds a few practical problems (atoi, Basic Calculator, Job Scheduling). If you have about two months, follow its weeks in order.
- **NeetCode 150** (see [`../neetcode/README.md`](../neetcode/README.md)) is the broader version of Blind 75, grouped by topic.

**Notes on accuracy:**

- Both lists are reproduced from memory. The Blind 75 list is stable (it has not changed since the original post). Grind 75 is generated by a configurable site (techinterviewhandbook.org/grind75); this table follows its default 75-question, 8-week plan as I remember it. **The week boundaries are the part I am least sure of**; a few problems may sit one week earlier or later on the live site.
- Rows with a note point to an AlgoExpert-style problem that is the same algorithm with a different interface; the note says what differs.
